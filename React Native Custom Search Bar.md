## ❓ What Is a Search Filter

| **Term** | **Description** |
|-----------|-----------------|
| **Debounce** | Delay before running |
| **Fuzzy Search** | Partial match |
| **Predicate** | Match function |
| **useMemo** | Cached computation |
| **FlashList** | Fast list renderer |
| **Chained Filter** | Multiple rules |

**Why use a good filter?**
- ✅ Instant results
- ✅ Smooth scrolling
- ✅ Fewer re-renders
- ✅ Better UX
- ✅ Free guide

## 🚀 Quick Start Guide

| **Step** | **Action** | **Time** |
|----------|-----------|----------|
| 1 | Prepare your data array | ~5 min |
| 2 | Add a debounced search input | ~10 min |
| 3 | Write the filter predicate | ~10 min |
| 4 | Memoize the filtered list | ~5 min |
| 5 | Render with FlashList | ~10 min |
| 6 | Add extra filter chips | ~10 min |

> **💡 Tip:** Always debounce the input by at least 250 ms — instant filtering kills performance on big lists.
